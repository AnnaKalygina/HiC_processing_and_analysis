### Data for Use on the SHERLOCK Cluster

I processed data from various sources for four cell lines: 

- **GM12878** (both HiC and MicroC)
- **K562** (both HiC and MicroC)
- **CHM13** (HiC)
- **HG002** (HiC)

The fully processed data and intermediate files are available on the SHERLOCK cluster in dedicated directories, organized by cell line and method. You can access these files at `/oak/stanford/groups/altemose/kalyanna/<cell_line>_<method>`, for example, `/oak/stanford/groups/altemose/kalyanna/GM12878_hic/`. Additional protocols for how the data was processed could be found at the [processing section](../processing).

These repositories are gzipped for efficient storage and can be easily accessed by unzipping the files. Additionally, the reference genome sequences and associated annotation files are stored in the `/oak/stanford/groups/altemose/kalyanna/reference_genomes/` directory.

**Note:** These files were constructed using data from various sources, resulting in differing coverage levels. When comparing different cell lines, you may need to adjust for coverage differences. This can be done by normalizing to either the lower or higher coverage, depending on your analysis requirements.

In each cell line repository, I provide pre-processed data suitable for any part of a downstream Hi-C analysis: 

- **rawdata** folder contains FASTA files with the original sequence data.
- **mapped_pairs** folder contains reads aligned to reference genomes.
- **valid_pairs** folder contains valid pairs with registered ligation events.
- **cools** folder contains contact frequency matricies in .cool format. The matrices have been normalized and do not require additional balancing.
- **npz** folder contains the same matricies in np.array format compatible to be displayed in Jupyter Notebook.


### Additional data modifications

The data could be stored in the `.mcool` format, which allows for the storage of multi-resolution Hi-C matrices within a single file. These `.mcool` files could be generated by aggregating data from 10 kb resolution (or any available lowest resolution) `.cool` files using the `zoomify` command from the Cooler package:

```
cooler zoomify GM12878_hic_10k.cool --out GM12878_hic_10k_to_320k.mcool
```

You can download these `.mcool` files and load a specific resolution in Python with the following command:

```python
import cooler
c = cooler.Cooler('GM12878_hic_10k_to_320k.mcool::resolutions/10000')
matrix = c.matrix()
```
